# Portfólio QA - Vladimir Macedo

Portfólio profissional para publicação no GitHub Pages.

## Publicação
1. Crie um repositório chamado `SEUUSUARIO.github.io`.
2. Envie todos os arquivos deste projeto para a branch `main`.
3. Vá em Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Branch: `main` e pasta: `/root`.
6. Salve e aguarde a publicação.

## Personalização
Edite os links do LinkedIn e GitHub em `index.html` e adicione seus PDFs na pasta `documentos`.
